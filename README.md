# AI 窗口

一个**纯本地**的个人 AI 情报控制台（3D 科幻 HUD）：打开即保留上一次的历史记录，并在后台静默同步当日最新信息，今日新增条目自动标记 **NEW**。内容按「AI 汇总 → 前沿技术 → 商机雷达 → AI 大事件」呈现。

## 特点

- 纯静态前端（HTML / CSS / JS / 本地 vendored three.js），无后端、无数据库。
- 浏览器直接调用千问 / DashScope 的 OpenAI 兼容接口，开启 `enable_search` 联网检索。
- **API Key 只保存在你自己浏览器的 localStorage**，不进入代码、不上传任何服务器。
- **历史保留 + NEW 标记**：每次拉取与缓存按稳定 id 合并，未见过的条目标 NEW 并置顶，历史保留 21 天。
- **静默同步**：每天首次打开自动后台拉取（可在设置关闭），不阻塞已缓存内容的展示。
- 四大板块：AI 汇总、前沿技术（原理解读卡片）、商机雷达（AI 赛道 / 国家政策 / 本地机会三类融合、按赛道标签区分）、AI 大事件。
- 3D 控制台背景：轻量 WebGL 星域，软件渲染 / 低帧率自动降级为静态或关闭，可在设置手动开关。
- 可搜索的模型选择器（拉取并缓存可用模型列表）、可配置超时与地区、可读的错误提示。

## 本地运行

需要 Node.js（本项目在 Node v16 下验证）。

```bash
cd /d D:\ai-fxb
node server.mjs
```

然后浏览器打开 http://127.0.0.1:5178 。

或直接双击 `启动.bat`（Windows），会自动起服务并打开浏览器。

## 首次使用

1. 打开右上角「设置」。
2. 填入你的 DashScope API Key（默认 Base URL 为 `https://dashscope.aliyuncs.com/compatible-mode/v1`）。
3. 选择模型（可点「拉取模型」获取可用列表）。
4. 保存后即可生成内容。

```
├─ web/

│  ├─ styles.css
│  └─ app.js

```

## 说明

- 请通过 `http://127.0.0.1:5178` 访问，不要用 `file://` 直接打开 HTML，否则浏览器跨域限制会导致接口调用失败。
- 本项目为个人本地工具，API 调用按你自己的千问 token 计费。
